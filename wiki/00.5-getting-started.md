# 0.5 — Getting Started

## Prerequisites

- Node.js + pnpm (`pnpm-workspace.yaml` present, `pnpm-lock.yaml` is the lockfile).
- A Neon Postgres branch — provisioned via the Neon CLI (`neon connection-string main --pooled --database-name neondb`), never hand-written.
- `.env.local` populated with `DATABASE_URL`, `DATABASE_DIRECT_URL`, `GROQ_API_KEY`, `REASONING_MODEL`, `FAST_MODEL`, `OPENROUTER_API_KEY`, `FALLBACK_MODEL`, `CONGRESS_GOV_API_KEY` (`src/ai/models.ts:4-14`, `src/server/congress.ts:15-18`).

## Install and run

```bash
pnpm install
pnpm drizzle-kit generate   # only after editing src/db/schema.ts
pnpm drizzle-kit migrate    # applies migrations, direct connection only
node scripts/seed-golden.ts # loads the CCPA golden fixture (fixtures/golden/ccpa-2018/)
pnpm dev                    # next dev
```

Then visit `http://localhost:3000`. `src/app/page.tsx:11-23` lists public projects; the seeded CCPA project is reachable at `/p/<slug>/source`.

## The kill test

Before trusting any change to `src/core`, run:

```bash
pnpm test
```

`src/core/__tests__/golden.ts` loads `fixtures/golden/ccpa-2018/*.json` (an original CCPA-derived formalization, a repaired one, and a recorded exploit candidate). The suite must show the original formalization as `SAT` (exploitable) and the repaired one as `UNSAT` (closed) for that same candidate — see [03 — Z3 Engine](03-z3-engine.md). If this regresses, stop and fix `src/core`; don't paper over it with UI work (`CLAUDE.md`).

## Where to read first

1. `src/core/ir.ts` — the Legal IR: `Formalization`, `PurposeContract`, `Candidate`, `RepairProposal` (Zod schemas, the shapes everything else passes around).
2. `src/core/engine.ts` — `certify()`, `retest()`, `enumerateCounterexamples()`: the only code allowed to call Z3.
3. `src/server/runs.ts` — how an HTTP request becomes a durable, resumable background run (`after()` + `run_events` table, no in-memory pub/sub).

## Sanity checks

```bash
pnpm typecheck   # tsc --noEmit
pnpm lint
pnpm exec playwright test e2e/demo.spec.ts   # the 3-minute demo path
```
